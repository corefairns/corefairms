COREFair — GitHub Pages upload guide (Android)

IMPORTANT: Upload the CONTENTS of this folder to the repository root, not the outer folder itself.

Correct repository layout:
index.html
app.js
styles.css
supabase-config.js
README.md
assets/corefair-logo.png
supabase/schema.sql

On GitHub mobile:
1. Open your repository and choose Add file -> Upload files.
2. Extract this ZIP on your phone first.
3. Select/upload the root files (index.html, app.js, styles.css, supabase-config.js, README.md) and the logo/schema files in their matching folders. If GitHub's mobile picker cannot upload folders, upload the files inside assets and supabase separately, creating those folders via Add file -> Create new file, e.g. assets/.gitkeep and supabase/.gitkeep, then upload files into each folder.
4. Commit changes to main.
5. Repository Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> /(root) -> Save.
6. Wait for the published URL shown on Settings -> Pages.

BACKEND REQUIRED:
Edit supabase-config.js and replace the placeholder URL and public anon/publishable key with your own Supabase project values. Never put a service_role or secret key in browser code.
Then open Supabase SQL Editor and run the contents of supabase/schema.sql.
Set the Supabase Auth Site URL and Redirect URLs to your published GitHub Pages URL.

A successful upload/deployment alone does not make Supabase features work until the backend is configured.
